# <nazev-nastroje>

Jedna až dvě věty: co nástroj dělá, na jaký systém a prostředí míří, s jakými oprávněními.

Než začneš, přečti [RISK.md](RISK.md).

## Co nástroj nabízí

Tooly, příkazy nebo skripty a co přesně dělají. U zápisových operací to napiš výslovně.

## Předpoklady

Účty, přístupy, verze klientů a závislostí (připnuté).

## Nastavení

Postup pro každého podporovaného klienta (Claude Code, Claude Desktop, Codex). Jeden krok = jedna akce.

## Ověření

Read-only kontrola, že nástroj funguje, a očekávaný výsledek.
